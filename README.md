## 🚀 Featured Web3 & High-Impact Projects

### ⚡ [VendorPulse — Decentralized B2B Vendor Management](https://github.com/ashishh-tech/stellar-vendorpulse)
> **The Trust Layer for B2B Supply Chains, Built on Stellar Soroban Smart Contracts.**
- Converts subjective supplier reviews into **immutable 4-axis performance telemetry** (Delivery, Quality, Payment, Communication) on Soroban.
- Features atomic **inter-contract communication** between `ReviewSystem` and `VendorRegistry` contracts, real-time Soroban RPC `getEvents` streaming, and full Freighter API integration.
- **Traction**: 53+ onboarded user telemetry records, 4.8/5.0 CSAT rating, 9/9 passing unit/integration tests, live production app, and Startup Track application package.
- **Tech Stack:** `Rust`, `Soroban SDK v22`, `Next.js 15`, `TypeScript`, `Tailwind CSS`, `Freighter API`, `Vitest`
